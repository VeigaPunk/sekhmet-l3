# SEKHMET — L3 Execution Substrate

## → [OPEN THE LIVE GITHUB PAGES SITE](https://veigapunk.github.io/sekhmet-l3/)

> **Power, made governable.**

Sekhmet is xbreed’s L3 execution plane: a governed, 64-task execution substrate beneath the Sol Ultra control layer.

The site explains:

- why the Sekhmet name fits the architecture—explicitly as a design metaphor, not a historical claim;
- the L1 control plane and L3 execution boundary;
- the eight-axis × eight-lens task field;
- one global `-j 64` wave per round;
- evidence admission, distillation, critique, Pareto filtering, and single-writer integration;
- the bounded two-to-four-round frontier cycle;
- what is spec-defined, proposed, historically benchmarked, and still unverified.

The GitHub Pages edition is intentionally static and dependency-free. Its published source lives on the `gh-pages` branch.
